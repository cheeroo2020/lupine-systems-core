How it works

Three layers.
Each one does one job.

AIVA picks the best route. RAIL runs it. CLOKED proves it happened. That's the whole system.

A
Intelligence

AIVA

Looks at the movement, generates three route candidates, scores them with an urgency-weighted composite utility function, and writes a plain-English rationale for the winner.

router.py3 candidates
scorer.pyweighted utility
selector.pywinner + why
R
Execution

RAIL

Takes the chosen route and runs it through a strict 5-state machine. Cannot skip. Cannot reverse. Every transition is validated or it fails loudly.

initiated › scored › selected › executing › done
C
Evidence

CLOKED

Every event — created, scored, executed — gets SHA-256 hashed and chained to the one before it. Tamper with anything, verification breaks instantly.

genesis → a3f9…
request_created → 7c2b…
routes_scored → 1e4d…
execution_done → 9f8a…

API · 5 steps

Every movement
takes the same path.

Ordered. Immutable. Cannot skip. Cannot rewind.

01 · POST
/create-movement

Opens the request and the evidence log.

02 · GET
/get-routes

AIVA generates 3 candidates.

03 · POST
/score-routes

Weighted scoring picks the winner.

04 · POST
/execute

RAIL walks the state machine.

05 · GET
/log

CLOKED returns the hash chain.

Show quick-start script → 
# Start
uvicorn src.api.main:app --reload

# Create a movement
curl -X POST "http://localhost:8000/create-movement?amount=500000&from_currency=AUD&to_currency=SGD&urgency=high"

# Get routes, score, execute, log
curl "http://localhost:8000/get-routes/{id}"
curl -X POST "http://localhost:8000/score-routes/{id}"
curl -X POST "http://localhost:8000/execute/{id}"
curl "http://localhost:8000/log/{id}"
