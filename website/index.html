Three-layer architecture

Each layer has one job. Each job is independently verifiable.

A

AIVA

Intelligence layer

Generates candidate routes, scores them using an urgency-weighted composite utility function, and selects a winner with a plain-English rationale.

router.py3 candidates
scorer.pyspeed · cost · reliability
selector.pywinner + rationale
R

RAIL

Execution layer

Runs the selected route through a strict 5-state machine. Steps cannot be skipped or reversed. Invalid transitions raise errors immediately.

initiated › scored › selected › executing › completed
C

CLOKED

Evidence layer

Every event is SHA-256 hashed and chained to the previous entry. Change anything after the fact and verification fails immediately.

API — 5-step flow

Every movement follows the same ordered sequence. Steps cannot be skipped.

1
POST /create-movement

Create a movement request. Returns request_id. Opens the evidence log.

2
GET /get-routes/{"{request_id}"}

AIVA generates three candidates — Fast, Cheap, Balanced — with speed, cost, and reliability scores.

3
POST /score-routes/{"{request_id}"}

AIVA applies urgency-weighted scoring and selects the winner with a plain-English rationale.

4
POST /execute/{"{request_id}"}

RAIL steps through the state machine: initiated → scored → route_selected → executing → completed.

5
GET /log/{"{request_id}"}

CLOKED returns the full evidence chain with every event, its SHA-256 hash, and chain_valid: true.

Quick start — bash pip install -r requirements.txt && uvicorn src.api.main:app --reload 
# 1. Create a movement request
curl -X POST "http://localhost:8000/create-movement?amount=500000&from_currency=AUD&to_currency=SGD&urgency=high"

# 2. Get routes  (use request_id from step 1)
curl "http://localhost:8000/get-routes/{request_id}"

# 3. Score and select
curl -X POST "http://localhost:8000/score-routes/{request_id}"

# 4. Execute
curl -X POST "http://localhost:8000/execute/{request_id}"

# 5. View evidence log
curl "http://localhost:8000/log/{request_id}"
