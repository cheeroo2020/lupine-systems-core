How a route is scored

Every candidate is reduced to one comparable number.

U(R) = w₁·Speed + w₂·Cost + w₃·Reliability
speed = 1 − t / t_max  ·  cost = 1 − bps / bps_max

Speed is in hours, cost in basis points, reliability already a probability — so each is normalised to 0–1 against the candidate set before any weight is applied. Only then can the weights mean anything.
